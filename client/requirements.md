## Packages
date-fns | For formatting dates nicely (e.g., "Oct 24, 2024")
framer-motion | For smooth animations (hero, cards, modals)
lucide-react | Beautiful icons (already in base, but listing for clarity)
clsx | Utility for constructing className strings
tailwind-merge | Utility for merging Tailwind classes

## Notes
- Payment proofs and event images use ObjectUploader (Replit Object Storage)
- Auth is handled by Replit Auth (useAuth hook)
- Wouter used for routing
- Styling uses Tailwind CSS with custom fonts
